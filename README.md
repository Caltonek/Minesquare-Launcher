# Minesquare Launcher Updates

> **Notice:** This repository is maintained solely for the distribution of updates to the Minesquare Launcher. It is not intended for direct download, installation, or general use.

## About This Repository

This repository serves as the official update repository for the **Minesquare Launcher**.

The contents herein are accessed and administered by the launcher as part of its update process. The files may be arranged specifically for automated deployment and should therefore not be regarded as a complete or independently installable release.

## Important Notice

**Please refrain from downloading, installing, or otherwise making use of files contained within this repository by hand.**

The contents may, at any given time:

- be incomplete or reserved exclusively for the launcher's update mechanism;
- rely upon other files or components within the distribution system;
- pertain to a particular release or revision of the launcher;
- be altered, replaced, relocated, or removed without prior notice.

Users of the Minesquare Launcher should obtain all updates **directly through the launcher**.

## Purpose

This repository exists to facilitate the launcher's automated update process, including:

- determining whether an updated version is available;
- retrieving the files required for an update;
- deploying revised versions of the launcher;
- maintaining the resources necessary for automated distribution.

## Manual Installation

This repository **is not an installation source**.

There should be no need to obtain individual files from this repository in order to install or operate the Minesquare Launcher.

Should an issue arise with the launcher or its update process, please allow the launcher to perform the requisite update automatically rather than attempting to obtain or install files from this repository manually.
